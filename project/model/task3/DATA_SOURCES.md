# Task 3 Data Notes

Task 3 can read two kinds of data:

```text
outputs/*.csv          model outputs from a full run
sample_data/*.csv      small synthetic files used for examples
```

The public repo does not ship the full output tables. When those files are
missing, use the sample data only for checking schemas and imports.

## Expected Output Files

```text
attendance_impact.csv
travel_burden.csv
revenue_sharing.csv
playoff_probability.csv
summary_statistics.csv
```

These files are generated by the Task 3 scripts during a full run.

## Rebuilding Outputs

```bash
python -m project.model.task3.main
python -m project.model.task3.task1_impact --team LVA --expansion-city Toronto
```

Large simulation dumps and generated figures should stay out of Git.
